# Student Task Manager

A simple and user-friendly web application that helps students manage their daily tasks and track their progress.

## 🌐 Live Demo

https://korupuripallavi.github.io/student-task-manager/

## 📌 About the Project

Student Task Manager is a web-based task management application developed using HTML, CSS, and JavaScript.

The application allows students to add tasks, assign priorities, mark tasks as completed, delete tasks, and filter tasks based on their status.

Tasks are stored using the browser's Local Storage, so they remain available even after refreshing the page.

## ✨ Features

- Add new tasks
- Set task priority:
  - Low
  - Medium
  - High
- Mark tasks as completed
- Delete tasks
- View all tasks
- View pending tasks
- View completed tasks
- Display task statistics
- Save tasks using Local Storage
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- GitHub Pages
