# 📝 To-Do List

A clean and responsive **To-Do List web application** built with **HTML5, CSS3, and Vanilla JavaScript**. The application allows users to add, complete, and delete tasks while automatically persisting their task list using the browser's **Local Storage API**.

* ➕ Add new tasks

## ⚙️ How It Works

### Add Tasks

Enter a task in the input field and click **Add**. JavaScript dynamically creates a new task and adds it to the list.

### Complete Tasks

Click a task to toggle its completed state. Completed tasks are visually indicated with a checkmark and strikethrough styling.

### Delete Tasks

Click the **×** button beside a task to remove it from the list.

### Persist Tasks

The application stores the current task list in the browser's **Local Storage**. Saved tasks are automatically restored when the page is refreshed or reopened in the same browser.

## 🚀 Getting Started

### Prerequisites

No frameworks, packages, or additional dependencies are required.

